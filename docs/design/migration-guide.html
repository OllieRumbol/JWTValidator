Migrating from 1.x

Version 2.0.0 renames no classes or methods. Six changes can still affect your code. Check each one before you upgrade.

Summary of changes

Change Affects you if What to do
.NET 10 onlyYour project targets .NET 9 or older.Move to .NET 10, or stay on 1.0.3.
Minimum secret lengthYou use WithSigningKeyFromSecret.Use at least 32 bytes for HS256.
Expiry in UTCYou use WhenDoesJWTExpire.Convert to local time yourself if you need it.
IsEmpty on nullYou call it on a dictionary that can be empty or null.Check code that relied on the old result.
Logging stays offYou read IdentityModel messages while you debug.Turn it on in your own app.
IdentityModel 8Your app also uses IdentityModel packages directly.Move them to version 8 too.

.NET 10 only

AFFECTS YOU IF

Your project targets .NET 9 or older.

Version 2.0.0 targets net10.0 only. .NET 6, 7, 8 and 9 are no longer supported. Move your project to .NET 10, or keep using 1.0.3, which stays on nuget.org.

Minimum secret length

AFFECTS YOU IF

You use WithSigningKeyFromSecret.

A secret shorter than the minimum for the token's algorithm no longer validates: 32 bytes for HS256, 48 for HS384 and 64 for HS512, counted in UTF-8. ValidateJWT throws and TryValidateJWT returns false.

Expiry in UTC

AFFECTS YOU IF

You use WhenDoesJWTExpire or HasJWTExpired.

WhenDoesJWTExpire now returns UTC, not local time. HasJWTExpired now gives the correct result in every time zone.

IsEmpty on an empty or null dictionary

AFFECTS YOU IF

You call it on a dictionary that can be empty or null.

1.0.3 returned false for an empty dictionary and threw for null. 2.0.0 returns true for both.

Personal-data logging stays off

AFFECTS YOU IF

You read IdentityModel messages while you debug.

The library no longer turns on personal data in IdentityModel messages. To see it while you debug, set IdentityModelEventSource.ShowPII = true in your own app. Debugging has the details.

IdentityModel version 8

AFFECTS YOU IF

Your app also uses the Microsoft IdentityModel packages directly.

The package now depends on version 8, not version 6. Move your own references to version 8 too.

Other changes

  • With lifetime validation on, a token whose expiry is after 19 January 2038 now validates.
  • The dictionary extension methods no longer throw for a null dictionary, or a null value inside a list.
