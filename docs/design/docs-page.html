Validation options

Build a JWTValidatorOptions object. It says where the signing keys come from, and which parts of the token to check.

Choose a signing key #

Start with Create(), then choose one source for the key:

  • WithSigningKeyFromSecret(secret) for a token signed with a secret.
  • WithSigningKeyFromOpenIdUrl(url) for a token from an OpenID Connect provider.

CHANGED IN 2.0.0

A secret shorter than the minimum for the token's algorithm no longer validates. Read the migration guide.

Minimum secret length

The length is counted in UTF-8 bytes.

Algorithm Minimum secret length
HS25632 bytes
HS38448 bytes
HS51264 bytes

Add checks and build #

Add only the checks you need. WithExpiryDate() allows a clock skew of 5 minutes.

Reference #

WithSigningKeyFromSecret

Uses a secret to check the signature of an HMAC-signed token.

public IJWTValidatorOptionsBuilderFinisher WithSigningKeyFromSecret(String secret)
Parameters
secret: the shared secret. It must not be empty.
Returns
The builder, ready for checks or Build().
Fails when
The secret is shorter than the minimum. Validation then fails, not the builder.
